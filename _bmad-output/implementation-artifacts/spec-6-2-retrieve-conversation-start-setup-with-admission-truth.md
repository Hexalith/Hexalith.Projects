## Design Notes

**`asOf` proof placement.** The supported `asOf` must equal the read model's watermark timestamp, asserted exactly in persisted/handler tests with a fake clock and a known watermark. `observedAt` is excluded from shadow field equivalence: the legacy value is a per-request wall clock that was never evidence, so there is no meaningful equivalence to assert against it, and a plausibility window would only add a threshold that flakes under load and drifts under rebuild. The binding is proven where it can fail for the right reason.

**Source-kind overlap precedence.** A kind appearing in both preferred and excluded lists is excluded. Fail-closed matches the `LinkedSourcePolicy.None` closed-default posture and the project rule to prefer the more restrictive option; rejecting overlap outright would turn already-stored setups into hard read failures and require a migration for an unreported problem.

**Shadow comparison and intended divergences.** Story 3.5 put an audit read and an admission read on one route, which is why Archived and stale reads look like FR conflicts but are not. The supported query answers the admission question only; the legacy route keeps answering the audit question until Story 6.7. Where the two must disagree -- Archived, and non-current evidence -- the comparator records an expected status pair and asserts that pair instead of diffing bodies. This is deliberately not a normalization: normalizing these away would erase exactly the admission truth this story exists to prove, and diffing them would pull protected setup values into comparator failure output.

The supported response should wrap or compose the existing bounded `ConversationStartSetup` values with the accepted shared AD-32 snapshot rather than mutate the legacy OpenAPI DTO in place. This preserves Story 3.5 client compatibility and gives Story 6.7 a finite shadow/cutover boundary. `IDomainServiceAdmissionStage` is deliberately excluded: it gates command pre-commit processing and does not express read/first-response admission.
