# Historical configuration evidence

The twelve entries in [manifest.json](manifest.json) are inactive historical
NuGet configuration and copied SDK evidence. They are stored as deterministic
gzip data so that historical policy declarations cannot act as repository build
configuration. No active product configuration, validator, audit rule or original
receipt changed. Each archive decompresses to the exact recorded source Git blob.
The manifest preserves its original relative path, Git mode, byte count and hashes.

Historical receipts continue to name their original paths. Reconstruct their
source layout only inside disposable scratch when inspecting or replaying them.
From the Projects repository root:

```bash
run-with-temp python3 - <<'PYTHON'
import gzip, hashlib, json, os
from pathlib import Path
def require(condition, message):
    if not condition:
        raise RuntimeError(message)
manifest = json.loads(Path('_bmad-output/implementation-artifacts/evidence/audit-policy-history/manifest.json').read_text())
scratch = Path(os.environ['TMPDIR']).resolve()
for entry in manifest['files']:
    packed = Path(entry['archivePath']).read_bytes()
    require(hashlib.sha256(packed).hexdigest() == entry['archiveSha256'], 'Archive hash mismatch')
    original = gzip.decompress(packed)
    require(len(original) == entry['originalBytes'], 'Original size mismatch')
    require(hashlib.sha256(original).hexdigest() == entry['originalSha256'], 'Original hash mismatch')
    target = scratch / entry['originalPath']
    target.resolve().relative_to(scratch)
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_bytes(original)
    target.chmod(int(entry['originalMode'], 8) & 0o777)
print('Exact historical files restored under', scratch)
# Inspect or replay the historical evidence here, before run-with-temp cleans up.
PYTHON
```

These archives are evidence, not inputs for active restoration, build or release.

To reproduce compression, use the Python and zlib versions recorded in the
manifest and `gzip.compress(original, compresslevel=9, mtime=0)`, where `original`
is the recorded source Git blob. This fixes the compression level and timestamp;
verify the generated bytes against `archiveSha256` before replacing an archive.
