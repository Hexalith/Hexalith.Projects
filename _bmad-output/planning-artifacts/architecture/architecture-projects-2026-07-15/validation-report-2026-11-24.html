C2 · Critical

A Folder binding can be installed without a current AD-35 claim

AD-35 governs how a task acquires the exclusive Folder claim, but no AD requires the projects aggregate to refuse a binding command that lacks a current claim receipt. AD-17 meanwhile asks for command equivalence with the current fold, which replaces an Active Project's Folder on a Boolean ReplacementConfirmed with no exclusivity check. After cutover, a v1 PUT …/folder, a restore or a direct Gateway command can therefore bind Folder F to Project P while Project Q holds F's claim. Either way two Active Projects share one Folder, AD-3 breaks, and F's readers gain the other Project's context.
