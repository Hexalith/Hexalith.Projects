# Owner tasks and acceptance

This is a proposed prerequisite work package, not a sprint story, implementation approval or a change to Story 6.4's status. Repository maintainer names and dated decisions remain to be supplied. Each owner may accept or amend the proposal in its own repository; any amendment must be reconciled here before consumption.

## Required owner-review record

For each task, the eventual acceptance record must name the maintainer and repository, date, accepted/amended/rejected decision, exact contract version/discriminator/field schema, permission/action/workload policy, freshness/head/generation semantics and configured thresholds, limits, source revision, published dependency closure and hashes, commands and actual artifacts, compatibility/rollback scope and outstanding blockers. This spec provides the proposal only; all owner decisions are pending.

Record G-2 Conversations/Folders outcomes separately. Record EventStore and Projects evidence separately from owner authority. Keep G-4's pinned tool, module manifest, reads profile and authenticated persisted Story 6.4 run as a separate prerequisite work package. The eventual Story 6.4 run must still generate real `evidence/epic6/6.4-resolution-reads.trx` and `.json` after its gates and handlers exist.
